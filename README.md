# Deep-Dive-AI-Project
For Deep Dive AI Camp at University of Dallas Texas. 

# Soccer Sim W/Q-learning:

Basic Idea:

- Train a model to control a team in soccer with Reinforcement Learning
- The Game Functions Like Fifa: as in you control player at a time, with the option to switch between players
- At the end pit them against eachother to see which is the best model, for a sort of demo

Constraints:

- Each team will have 5 players for minimizing complexity
- Graphics won't be all that great, don't expect a AAA Game.

# Accomplishments:
- Basic AI Working
- AI defends, steals, passes, and sometimes but rarely switches

# Failures:
- Fails at complex switching
- Some players sit still and idle even when they are nearby due to the model focusing heavily on a given player

# Note:
- The build is not the build used to play the game, but the build used to train the model
- Python Enviornment files for training are not included for storage sake
